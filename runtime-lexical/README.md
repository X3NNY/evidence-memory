# EvidenceMemory 零模型版本

版本 `text-http-lexical-v1`。仅词法与对话结构检索，不创建 Embedding 或 LLM 客户端，不读取旧向量缓存；新写入和新问题也无需付费模型。Answer/Eval仍由赛事平台负责，已有服务器、存储与带宽成本仍存在。

## 检索与存储

复用共享 MemoryEngine 的 BM25 分支与稳定256词原文块。查询明确提到原文检测到的对话人物时，使用细粒度段落、词干正文信号、说话人与会话结构、跨块连续性、原文边界窗口与会话框；其他文本融合原始BM25和正文词干BM25，固定各占0.5的RRF，再返回完整父块。所有返回内容来自原始记忆，不生成最终答案，不使用金标或题号特判。

SQLite原子幂等写入、generation快照、用户隔离、增量可见、持久化与有界响应缓存继续保留。服务以 `AML_RETRIEVER=lexical` 启动；Health报告 `embedding_mode=none`。模型提供者注入会被拒绝。CLI阻断外部连接和DNS，仅允许本机事件循环与健康检查所需的回环连接；服务仍接受HTTPS代理转发的入站请求。

## 启动

生成独立的 Memory System Key 文件，并设置它的路径。此密钥只用于服务鉴权，不是模型Key。

```sh
export AML_MEMORY_SYSTEM_KEY_FILE=/absolute/path/to/memory-system-key.txt
docker compose up -d --build
curl http://127.0.0.1:8788/health
```

本部署包内的Dockerfile与Compose默认使用lexical，不需要模型密钥、模型端点、Embedding缓存或模型权重。持久化数据在独立卷中，原hybrid版本数据不覆盖。公网应通过HTTPS反向代理接入，并为16以上外部并发在代理层排队，为进程内部16连接限制预留余量。

## 评测边界

同一100题、同一48k字符预算的实际引用轮次token覆盖：

| 数据集 | 冻结混合v8 | 无模型lexical-v1 |
|---|---:|---:|
| LoCoMo-Refined（50题） | 97.50% | 87.83% |
| LongMemEval-S（47道有证据题，另3道拒答题） | 77.32% | 50.26% |

这是重复用于开发的小样本检索结果，不是QA或官方成绩。免费方案存在明确质量损失。旧v8的100题输出在兼容回归中逐条保持一致，原44分及其537份冻结文本结果/报告保留。新版本100题向量读取、向量存储、模型提供者创建与模型API调用均为0。439项测试通过，覆盖长消息的段落到父块映射与无模型重启。

本轮使用原hard100及其原始记忆离线重放，不新增模型请求或subagent。免费版本与冻结v8分别保存，旧混合版本的官方Smoke成绩不能沿用给本版本。本版本需要独立固定commit、登记接口并重新通过官方Smoke；付费Full未启动。

旧混合模式仍保留以供兼容回归；它不是这个部署包的运行配置。历史核心与文本适配器源码保持冻结，免费方案仅改变在线召回通道及其配置。
